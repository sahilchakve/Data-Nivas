Data Nivas app (sirf AI ka chat wala app, launcher nahi).

1. app/src/main/res/values/strings.xml mein server_url ko apne Render server ke https link se badlein.
2. Naya GitHub repo (jaise data-nivas-app) banayein, aur ye files upload karein.
3. PASTE_THIS_workflow.txt ka text .github/workflows/build.yml mein paste karein.
4. Actions > Build APK > Run workflow chalayein, APK download karke install karein.
